# Darwin inventory data provenance

The five Darwin CSV files and their JSON receipt are generated by
`scripts/catalog/darwin_syscall_inventory.py`. Apple distributes their XNU
source under the Apple Public Source License 2.0. A verbatim license copy from
the reviewed source input is retained as [APPLE_LICENSE](APPLE_LICENSE); its
SHA-256 is
`e5881019d8766c1e88a5fe1dbca4ba40c78011d41fcb18f6e9f50df60182685b`.
The [upstream notice inventory](UPSTREAM_NOTICES.md) retains the additional
CMU, OSF, Apple free-copyright and NeXT notices or literal markers carried by
admitted files.

The history bundle is
`darwin-xnu-syscall-history-first-pass.zip`, SHA-256
`d6324bdc100c65f94396e2458b3f2dbe199d2fcc2e18d6c1cfd05f9fab94ee16`.
Its latest export is labelled `xnu-12377.121.6`, but its recorded
`xnu-main.zip` input, SHA-256
`95fa2c70902b240521c2540858270708596208dbb5fc482519b32382b0ba26e2`,
has ZIP comment `f6217f891ac0bb64f3d375211650a4c1ff8ca1ea`. That is an earlier XNU commit,
not the commit for the labelled tag.

The generator therefore requires a separate exact `xnu-12377.121.6` source
tree for the latest snapshot. The tracked
[`darwin-xnu-source-manifest-xnu-12377.121.6.json`](darwin-xnu-source-manifest-xnu-12377.121.6.json)
admits 99 source files by path, role and SHA-256 before any source is parsed.
That set contains all 85 `.defs` files, the nine primary and selector sources,
and five MIG build or generation inputs. It is bound to commit
`ac9718fb1af618d5ce8678d0dc6e8a58f252216f`. An extracted tree without `.git`
is accepted when every admitted byte matches. When `.git` is present, its HEAD
must also match the pinned commit, but checkout-local state is not serialized
into generated output.

Exactly three of the nine initially reviewed source files are byte-identical
between the earlier input and exact tag: `bsd/kern/syscalls.master`,
`osfmk/i386/machdep_call.c` and `osfmk/i386/Diagnostics.h`. Six differ:
`osfmk/kern/syscall_sw.c`, `osfmk/arm64/proc_reg.h`,
`osfmk/arm64/machine_routines.c`, `osfmk/i386/Diagnostics.c`,
`bsd/sys/proc_info.h` and `bsd/sys/proc_info_private.h`.

The primary active and gap CSVs retain the history bundle's normalized BSD and
x86 machdep rows and rebuild the Mach, ARM platform and diagnostic rows from
the exact source. Diagnostic rows carry separate declaration and implementation
receipts; `dgGzallocTest` and `dgPermCheck` remain conditional on
`DEVELOPMENT || DEBUG`. Exact extraction also retains the declared-only
`dg64` selector omitted by the history export, so the corrected all-status
total is 845 rather than 844. The active total remains 533.

The `proc_info` CSV is an exact-header extraction. Its `implemented` marks mean
that Native-Kernel issues the selector through a shipped typed mechanism and
has a named source or positive-spec witness; they are not whole-domain support
claims. The MIG CSV records each subsystem declaration, admitted source hash,
kernel build role and libsyscall header-export role. It remains a subsystem
source map: 37 of its 52 subsystem rows have a kernel-build role and 17 have a
libsyscall header-export role. It is not a configuration-resolved per-routine
ABI catalog.
Native-Kernel's coverage and decision columns are local annotations; they are
not Apple support or compatibility claims.

The secondary-catalog candidate CSV is a heuristic audit queue derived from
BSD prototype parameter names. It is neither an upstream table nor a claim
that every selector-bearing operation has been detected.

The project-level `LICENSE` continues to cover Native-Kernel's own source and
documentation. This file records the separate provenance and terms of the
upstream-derived data rather than silently treating it as project-authored.

The catalog tooling floor is Python 3.8. Normal generation only consumes the
tracked source manifest. Refreshing that trust root is a separate explicit
operation and requires a clean Git checkout at the pinned commit:

```sh
python3 scripts/catalog/darwin_syscall_inventory.py \
  --latest-xnu-root /path/to/xnu-12377.121.6 \
  --write-source-manifest
```

The reviewed GitHub repositories and search receipts that led to these source
choices are recorded in
[Darwin catalog source register](../darwin-catalog-sources.md).
